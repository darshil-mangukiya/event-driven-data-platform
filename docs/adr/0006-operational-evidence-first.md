# ADR 0006: Add Operational Evidence Instead of More Surface Area

## Status

Accepted

## Context

Local platform demos can over-expand by adding many shallow integrations. This project should demonstrate reliability and operating depth.

## Decision

Add DLQ replay tooling, data quality checks, benchmark result capture, dashboard views, ADRs, and threat/governance docs before adding unrelated features.

## Consequences

The project becomes easier to evaluate because it shows how the platform is operated, tested, measured, and recovered.
